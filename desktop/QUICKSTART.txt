Gozero助手 Beta 1.02 · 构建 1.0.37 · 使用指南

本版更新：BNT 核心升级为0.2.1，新增AVX2 stream预取候选路径，复用固定寻址表并减少压缩函数调用开销。默认保持旧路径，新路径只通过自动调优实测择优启用，避免高并发回退。
更新后请在BNT工作台安装新版内核，再运行一次“自动调优”；新内核会使旧版本测速缓存失效。不同CPU、内存通道和线程数的提升幅度不同。
保留功能：按实时可用内存和逻辑线程数设置性能预算；默认域名端口14444，旧默认地址自动迁移。
保留修复：BNT 连接分阶段诊断（DNS / TCP / TLS / 登录 / 等待任务），失败按5/10/20/40/60秒间隔重试并轮换已配置备用节点。未收到任务不重复输出0算力。
BNT 工作台矿池地址旁“检测连接”会登录并等待任务验证，不启动CPU计算。日志可判断超时发生在哪个阶段。
TCP连接超时表示端口尚未连通，应排查网络路径、矿池监听或服务器防火墙；软件重试无法保证修复服务器端故障。
保留1.0.29的Electron兼容SHA3校验修复。

一、安装与启动
适用于 Windows 10 / 11 x64。请先安装显卡厂商驱动。
将压缩包完整解压到一个新文件夹，双击 GozerAssistant.exe 启动。
请保留 DLL、resources、locales 等文件，不要只复制 EXE。
日常使用无需安装 Node.js 或 Python。程序不会自动开始挖矿。
顶部语言菜单或“偏好与保护 → 界面语言”可切换中文、English、日本語、Русский。
切换即时生效并自动保存，同步主窗口、悬浮卡片和托盘菜单；不会启动或停止挖矿。
矿工原始输出和设备原始识别信息保留来源内容，便于排查问题。

二、选择设备
打开“设备总览”，等待自动扫描 GPU、CPU、内存、主板和 BIOS。
勾选参与挖矿的显卡；多张同型号显卡按 PCI 地址区分。
更换设备或驱动后可点击“重新扫描”。未识别的旧设备选择可手动清理。
NVIDIA 可显示驱动支持的温度、功耗、频率、负载及 PCIe 参数。
未支持或暂时无法读取的参数显示“—”，不会生成模拟读数。

三、开始挖矿
币种与内核库：工作台点击“内核库”，挖矿时仍能浏览与安装其他内核。
正在使用的内核禁止覆盖安装。启动其他币种前会提示停止已有任务。
NOID 下载显示连接、字节进度、校验及解压状态；网络失败会在系统网络和官方 GitHub 直连间重试，最多3次。
下载始终校验官方固定版本的压缩包、EXE和依赖；没有安装完成之前不会启动矿工。
窗口默认792×594（放大10%），工作台突出钱包、矿池和线程设置，底部日志自动填充。

BNT（Blocknet）CPU矿池挖矿：
随附 Gozero Blocknet CPU 0.2.1，调度优化 + Argon2id SIMD计算，内核费0%。
默认矿池 stratum+tcp://bnt.pool.gozero.trade:14444，支持另填主/备用池。升级会迁移旧的默认4444地址（包含双挖配置），保留其它自定义矿池。
每线程需要2 GiB计算内存，另预算128 MiB进程开销；取消固定8线程上限。按当前可用内存减去系统预留（至少4 GiB或总内存10%，取较大值），再结合CPU逻辑线程数计算上限。
节能50%、均衡75%、高性能100%分别使用上限的对应比例，向下取整；启动前重新读取内存，超限时提示重新应用档位。
例如64 GiB总内存、56 GiB可用、128逻辑线程，上限23线程，三档分别为11 / 17 / 23线程。实际以本机可用内存为准。
性能档位按上述内存上限分配线程；不按CPU逻辑线程数直接拉满。
主网地址有Base58校验和，非BNT地址不能使用。CPU温度和功耗尚未接入。
已验证真实矿池登录、获取任务与accepted份额，收益价格数据暂不提供。
源码与第三方许可证在 resources/app/native/bnt/source、third-party-licenses 中。

四、性能预算与温度保护
性能预算：50–64%为节能，65–89%为均衡，90–100%为高性能。
拖动滑杆后点击“应用”。悬浮卡片会显示当前已应用的模式与百分比。
最高档预留调度余量；预算不是显卡功耗上限，也不等于实时 GPU 占用率。
更改档位会重新积累算力统计。服务收款或切换时段暂不能调档。
GPU 温度保护默认90°C，可在“偏好与保护”中修改并保存。
达到阈值或已接入的温度传感器失联时会停止任务；无温度接口的设备不具备温度保护。

五、算力与收益
合计算力支持5分钟或10分钟统计周期，默认5分钟；停止后可更改并保存。
首轮显示暂估值，完整周期结束后保留该周期均值，待下一周期完成再替换。
缺测、采样覆盖率不足或已停止时会标注状态；统计值不等同于矿池有效份额算力。

工作台保留实时算力、5/10分钟均值及收益估算，不再提供独立收益测试板块或测试按钮。
在“偏好与保护 → 收益估算参数”调整电价、矿池费、整机功耗或刷新参考收益。
预计日净收益扣除软件费、已知内核费、填写的矿池费和电费。
7日与30日为当前条件下的线性推算；估算不等于实际到账收益。

“矿池实际收益”当前支持 Kryptex 的 PRL / QTC 地址查询。
NOID 支持 Suprnova 地址余额和支付查询；缺少可信币价时不显示美元估算收益。
显示余额、待确认收益、支付情况及最近支付记录，每60秒更新。

六、悬浮卡片与托盘
主窗口最小化或点击X会进入悬浮卡片，正在运行的任务继续。
拖动卡片顶部或底部可移动；点击↗恢复主窗口，点击“停止”结束任务。
卡片右上角X将其收起到系统托盘，任务继续运行。
双击托盘图标或右键选择“复原主窗口”可恢复。
选择“退出”会停止本程序的挖矿任务并关闭程序。

七、软件服务费
软件服务费为0.5%，挖矿任务适用，底部可查看规则及收款地址。

累计达到服务时段后，会临时切换收款地址，结束后恢复用户地址。
短测试的零碎服务时间会留存，并在后续任务中结算。
这不是每获得100币精确扣除0.5币；实际到账受算力、份额、矿池门槛和结算影响。

NOID 官方内核与自动连接（构建 1.0.12）
工作台 → NOID → 矿工内核，可选择默认推荐、Suprminer 1.9.27 或 Fl4shMiner 1.5.0。
默认推荐使用 Suprminer；已移除自研 NOID 选项和安装包内的自研 NOID 运行文件。
旧版自研内核选择会迁移至默认推荐；不会自动开始挖矿。钱包和矿池配置保留。
Suprminer：NOID 官方要求 NVIDIA 驱动610或更新；内核费0%。
Fl4shMiner：NOID内核费3%；可能要求关闭AI或调试应用，助手不绕过上游检查。
软件服务费0.5%独立于内核费及矿池费。
首次使用需点击“下载并安装”；从官方GitHub下载，ZIP及依赖文件通过固定SHA256校验。
当前为单币挖矿，不支持合并挖矿；温度保护默认90°C。

连接模式默认“自动适配（失败转 TCP）”，无需手动切换。
先按主节点、备用1、备用2检测原始连接；全部失败后，尝试官方Suprnova节点的兼容TCP。
兼容连接为非加密TCP 3337，通过HTTPS DNS获取当前地址，不固定写死矿池IP。
自定义矿池仅检测原始连接，不擅自替换协议或映射到其他矿池。
检测通过后将所选地址交给内核，运行中不自动切换NOID节点。检测最多45秒，可点击停止取消。
界面和日志会显示自动TCP回退及实际使用的节点。可手动选择原始连接或兼容模式用于排查。
“备用”按钮打开下拉选择窗口，支持不使用、预设地区、自定义，并保留完整地址输入。
“检测连接”不启动GPU；协议检测通过不等于矿池已接受有效份额。请以accepted及矿池记录核验。
安装可用表示文件校验通过，不代表性能保证。不同显卡和档位的算力需分别实测。

租赁市场会根据窗口宽高自动调整列数和每页条数；拉伸结束后合并请求，每页最多96条，避免无限渲染。

GPU＋CPU 双挖（1.0.25）
工作台顶部可切换 GPU挖矿、CPU挖矿、GPU＋CPU双挖；切换前须停止全部任务。
双挖同时运行一个 GPU 币种（PRL / QTC / NOID / YSR，可多卡）和 ZCD CPU。
两张任务卡分别设置收款地址、主矿池、备用矿池、内核、矿机名及性能。点击“设置”展开详细参数。
分别保存配置，再点击各自的启动按钮或“启动全部”；单独停止一张卡不会停止另一张。
内核仅在点击“安装内核”后下载/校验，软件安装包不包含 XMRig 可执行文件。
CPU 默认均衡75%，线程数按系统逻辑处理器计算，可手动调整；100%档允许全部逻辑线程。
GPU 保留运行余量。两路共享主机资源，CPU挖矿可能影响GPU算力，建议先使用均衡档。
实时算力和5/10分钟均值分别显示，不将不同算法的算力相加；缺失、过期数据显示 —。
日志支持 全部 / GPU / CPU / 错误 筛选；悬浮卡片同时显示两路状态、算力和预算。
两路分别按软件0.5%费率累计，沿用原账本；内核费与矿池费另外计算。
CPU启动至少需要4 GiB可用内存，运行时内存严重不足会停止CPU任务；GPU温度默认90°C保护。
此版本已通过双任务调度回归、四语言界面及原有单挖回归；未完成两路真实矿池长时间稳定性验证。

连接显示：矿池使用域名连接；日志与 BNT 连接检测仅显示域名、端口和阶段，不显示解析后的服务器 IP。其它内核日志中的 IP 也会自动隐藏。BNT 可使用 stratum+tcp://bnt.pool.gozero.trade:14444。

BNT 0.2.0 自动调优：
安装新版内核后，在 BNT 工作台点击“自动调优”。必须停止全部任务；该过程离线对比公开计算向量，不连接矿池、不产生收益。
按当前性能预算测试计算路径、线程数、核心绑定和大页策略，重复对照后应用推荐线程数。可随时取消；取消不会应用未完成的结果。
CPU及操作系统均支持时才能测试 AVX-512；每个候选先校验完整2 GiB算法向量。当前发行开发机不支持AVX-512，未实测该路径性能。
挖矿内核只使用当前进程已有大页权限，不自行提权；需要授权时使用下方说明的手动设置入口。大页不可用时自动回退普通内存，日志报告实际大页数量。
配置更换CPU、内存、内核版本、性能比例或线程数后，不匹配的调优结果不会用于挖矿；需重新调优。
自动调优输出是短期离线吞吐量，不能保证更长运行或矿池结算收益。线程越多不一定越快。

大页内存（1.0.36）：
CPU 工作台和设置页提供“开启大页内存”。点击确认后通过 Windows 管理员授权，只为当前账户添加“锁定内存页”权限。不同于增加虚拟内存/分页文件，不会增加物理内存或线程上限。
如果提示待生效，请自行注销重登或重启电脑（保存其他工作），再打开助手；不会自动重启。检测显示可分配仅表示小块测试成功，BNT 完整 2 GiB 工作区是否使用大页以实际线程数和日志为准。
没有已匹配调优方案时，启用后 BNT 默认尝试大页，失败自动回退；已有调优方案保留其计算路径、核心绑定和页面策略。重新自动调优可以比较大页与普通内存，最终采用实测较优策略。ZCD 的 XMRig 已请求大页，实际成功比例以内核日志为准。
本版只实测了状态检测和界面流程，管理员提权/账户授权及重登后分配仍需用户机器验证。

1.0.36 调优配置兼容修复：
兼容 1.0.33–1.0.35 的调优标识；大页权限变化不再让已有方案失效。内核二进制与算法未变，不自动修改用户的线程数或性能档位。重新调优以当前有效计算方案为基线。
启动时“优化”日志包含实际路径、线程数、档位、大页与核心绑定比例、配置来源。排查算力下降时请保留此行和“运行”日志。该修复针对配置回退问题，不能据此保证特定设备恢复到某个算力。

BNT 多内核（1.0.37）
在“币种与内核库 → BNT”下载 Seine 0.2.15，回到工作台选择内核、保存并启动。默认仍为 Gozero Blocknet CPU 0.2.1。Seine 内核费 2.5%（bntpool 1%），另有助手服务费 0.5%。Seine 采用 CPU 后端、TCP 主/备用矿池，线程数受可用内存限制。自研自动调优不适用于 Seine。

矿池查询（1.0.38）
选择 YSR、ZCD 或 BNT，使用对应 Gozero 矿池并保存收款地址后，工作台“矿池实际收益”自动查询余额、矿池估算算力、Worker、份额和支付。支付弹窗可以翻页。双挖模式点击 GPU / CPU 矿池账本查看对应任务。
仅查询公开地址，不需要密钥。算力约30秒、账本约60秒刷新；失败保留缓存并退避。
YSR 链上余额不等于本池收益；本池收益按已索引区块显示。ZCD/BNT 待成熟和支付预留均不是已支付，BNT 待成熟属于可变预估。支付门槛和成熟确认数来自矿池当前规则。
