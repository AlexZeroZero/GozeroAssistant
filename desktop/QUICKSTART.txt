- 填写自己的 j1 地址即可自动生成矿池登录身份，无需另填Token。
- 旧版空矿池配置自动迁移，已填写的其它矿池保持原样。
- 精简未使用的运行环境语言文件，保留中英日俄；MDS完整源码改为tar.xz压缩。

- 新增 Jetsam（JTM）TowerWalk CPU；支持单独 CPU 与 GPU＋CPU 模式。
- 核心 Gozero JTM CPU 0.3.1-gozero.3，基于官方 TowerMiner 0.3.1 开源编译。
- JTM 可使用默认Gozero HTTPS矿池，或点击“离线算力测试 · 30秒”。
- 离线测试不需要钱包、矿池或 Token，不产生收益；结果保留在运行日志。
- 线程数跟随性能模式，按逻辑线程预算，也可手动设置。更改前请停止 JTM。
- 保留 MDS 0.1.12-rc.2 和 3090 参数 U2 / B256 / N20992 / D4000。

JTM 使用说明
矿池换块期间若返回 code 20 / node preparing work，内核会等待有效新任务后恢复。
这不是TowerWalk算法规定的固定休息；本版未修改矿池服务，也未消除该等待窗口。
1. 币种目录选择 CPU → JTM，在内核库安装随附核心。
2. 无矿池时可离线测试。测试结束自动停止，日志显示实际 H/s。
3. 填写自己的 j1 主网地址，使用默认矿池；自定义矿池可另填HTTP/HTTPS地址和Token。
4. 服务端须支持 TowerWalk 的 jetsam_getBlockTemplate、jetsam_submitBlock
   协议。默认矿池按登录身份分账；自定义节点须允许指定收款地址。不能填写普通Stratum地址。
5. CPU 要求 SSE4.1 + PCLMULQDQ，按支持情况使用 SIMD；每条链占512 KiB。
   大页可使用已有权限；本版不自动修改系统权限。CPU 温度与功耗未接入。
6. 0.5%助手服务费地址已按确认配置；真实矿池份额、支付及服务费收款切换，
   仍需持续联调。本版不声称已完成支付结算验证。

性能说明
已进行算法金标和 nonce 校验、本地模拟 RPC、助手安装/启停/离线测速验证。
本版加入地址重算、BMI2双链寄存器循环与轮次乘法预计算，按CPU能力自动回退。
本机24线程相对上一轮候选为-0.13%至+2.42%，整机提升尚不稳定。
一组相对1.0.54约+6.70%，不保证其它CPU同幅提升；请保留旧版对照测试。
已选旧版JTM内核的配置自动切回默认推荐，请在内核库安装0.3.1-gozero.3。

开始使用
1. 从系统托盘退出旧版，将新 ZIP 完整解压到新文件夹，运行 GozerAssistant.exe。
2. 在左侧币种目录选择币种和设备。GPU＋CPU 模式通过GPU参数、CPU参数分别配置两项任务。
3. 填写自己的收款地址、矿池和矿工名；性能设置自动保存。
4. 在内核库安装所选内核。第三方 XMRig、Seine、NOID 内核需用户手动下载。
5. 点击一键挖矿。日志可筛选 GPU、CPU 或全部；停止按钮停止当前任务。
6. 关闭主窗口进入悬浮卡片；关闭悬浮卡片进入托盘。托盘右键可恢复或明确退出。
   程序启动不会自动开始挖矿；明确退出会停止所管理的挖矿进程。

MDS
- 默认 stratum+tcp://mds.gozero.trade:13333，只支持本版适配的 Gozero/native 协议。
- 必须使用 generate-mss 生成的 MSS 可重复收款地址并确认，不能使用 WOTS 一次性地址。
- 选择 MDS 后安装0.1.12-rc.2内核；旧内核配置自动迁移到默认推荐。
- 需 NVIDIA RTX 30/40/50 兼容显卡及支持 PTX9.0 的较新驱动。无需安装 CUDA Toolkit。
- 50/75/100 档对应45%/67.5%/90%计算预算。运行中停止后再切换档位。
- N/s 为本地执行的计算链工作量，可包含换任务时取消的未完成部分；不等于矿池结算算力。
- MDS 币价/收益估算未接入；以矿池账本为准。源码及验证说明在 resources/app/native/mds。

其它币种与费用
- ZCD 必须填写0x02永久收款地址；CPU线程根据逻辑线程和可用内存预算设置。
- BNT 默认 stratum+tcp://bnt.pool.gozero.trade:14444，线程数受算法内存需求限制。
- PRL/QTC/NOID 区域节点、备份和连接协议按矿池实际说明选择。
- 软件服务费0.5%以分时计算预算实现，不是精确按到账币数扣除。第三方内核和矿池费用另计。
- Linux 独立内核不包含助手抽水调度，使用方式见独立包 README.txt。
- 中文、英语、日语、俄语可在设置中切换；支持深浅色主题。
