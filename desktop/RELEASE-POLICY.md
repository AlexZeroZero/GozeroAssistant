# Release version policy

Public releases are named 2.0, 2.1, 2.2, 2.3 and so on. Do not reuse the
former Beta 1.02 display label or increment the old 1.0.x series.

- GitHub title: Gozero Assistant 2.0; tag: v2.0.
- package.json displayVersion: 2.0; version: 2.0.0.
- Next public release: 2.1 / v2.1 / internal 2.1.0.
- Keep three-component internal versions for Electron and signed update validation.
- Update both English and Chinese repository READMEs and QUICKSTART.txt.
- Publish the complete verified Windows ZIP and checksum; preserve existing releases unless explicitly requested otherwise.
- Clearly distinguish measured results from estimates and unresolved limitations.
