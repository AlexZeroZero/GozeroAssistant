Gozero · XMRig CPU 源码编译测试版 6.26.0-cpu.2

这是基于公开 XMRig 源码编译的 Windows x64 CPU 内核，不是全新自研算法。
支持 ZCD 使用的 RandomX v2（rx/2）。此内核已作为助手1.0.20的默认ZCD内核，官方版仍可手动选择。

已完成：
1. 编译完成；版本查询正常返回。
2. 使用 Gozero 助手生成的 rx/2 配置执行 --dry-run，返回 config OK。
3. 编译时关闭 GPU、HTTP 管理、MSR 和 DMI 组件。
4. 不安装驱动，不修改账户权限，不修改安全软件设置。

未完成：
实际矿池接受份额、收益结算和杀毒软件厂商复核。算力对比见 BENCHMARK-RESULTS.txt。
“启动正常”不等于“挖矿时不报毒”。本文件未经过发布者代码签名。
已知腾讯管家提示为“涉嫌病毒”，该描述不能确认具体检测原因或误报性质。

仅检查，不挖矿：
在解压目录的终端执行：
  .\xmrig.exe --version
  .\xmrig.exe --config .\dry-run.json --dry-run

dry-run.json 只用于配置检查，含无效测试收款地址和本机占位端口。
不要删掉 --dry-run 把该测试配置当作正式挖矿配置。
正式挖矿需要真实矿池地址、自己的永久收款地址和适合设备的 CPU 线程数。

费率：根据用户要求，本源码版本的内核开发者费为0%，官方未修改版本仍为1%。
助手的 0.5% 服务费由助手调度器独立管理，独立运行本 EXE 不包含助手调度。

源码与构建：
source.zip 是固定提交的上游源代码；source-changes.patch 是本地修改。
build.py、inputs.json、build-record.json、validation.json 记录构建和验证信息。
dependency-sources 包含关联库源码与许可证；XMRig 采用 GPL-3.0-or-later。
本次使用上游固定依赖 libuv 1.51.0、hwloc 2.12.1、OpenSSL 3.0.16；
这些版本未经过本项目完整安全审计，正式发布前仍需复核并更新依赖。

如仍被拦截，请保留风险名称、文件名与 SHA256，向腾讯提交样本复核。
本包不提供关闭防护、排除检测、混淆或隐藏挖矿行为的功能。

修复记录：cpu.1 在本机 RandomX 数据集初始化时发生内存访问异常，不能用于挖矿。
cpu.2 修复 JIT 内存权限切换的覆盖范围；完整离线哈希测试结果随包提供。
