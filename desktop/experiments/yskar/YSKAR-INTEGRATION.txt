Implementation:
- Gozero YSR CUDA 0.1.0 uses upstream SHA-256d functions and a new C# HTTPS host.
- Custom 136-byte LE header, extranonce at 120, nonce at 128; inclusive BE target.
- Midstate caching reduces per-nonce work to two SHA-256 compressions.
- Raw difficulty u32 is preserved after consensus v4; difficultyWert is for estimates.
- Bounded candidate list with overflow retry and submission backpressure.
- CPU rehash before submission, job/session invalidation and VarDiff target changes.
- Separate HTTP session per GPU; UUID resolved explicitly through CUDA Driver API.
- HTTPS certificate validation, bounded API requests, reconnect and backup URLs.
- Start-time GPU self-tests; verified bundled files; explicit start and stop.
- Assistant performance budget, temperature protection and five/ten-minute averages.
- 0.5% disclosed time-sharing fee; mining and benchmarks accrue the same ledger.
- Network difficulty/hashrate/reward refresh, gross YSR/day and 7/30-day projections.
- No verified USD price feed: USD price and net dollar income remain unavailable.
- Address ledger shows on-chain balance and returned reward history, not withdrawal balance.
