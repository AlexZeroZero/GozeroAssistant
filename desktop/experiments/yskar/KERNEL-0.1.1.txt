- Preserve complete candidate counting, 64-slot overflow retry and CPU verification.
- Startup validation: 17 independent hash vectors, 34 complete strided candidate
  sets checked against CPU SHA-256d, inclusive target, high nonce and overflow tests.
- Preserve explicit start/stop, 0.5% disclosed scheduler, 90 C default protection.
- Migrate an explicitly selected 0.1.0 engine to updated default without resetting
  user wallets, performance or temperature settings. New engine must be installed.
