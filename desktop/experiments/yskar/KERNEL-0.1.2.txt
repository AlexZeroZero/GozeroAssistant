Change: 16-word rolling SHA-256 message schedule with 64 explicitly unrolled
rounds. The double-SHA-256 consensus function, 136-byte header, extranonce,
nonce endian and inclusive target comparison are unchanged. Generated source
and generator hashes are retained in fast-sha-provenance.json. Upstream MIT
license and original copyright are preserved.

The reference path is retained. Startup validates both candidate paths, then
calibrates the kernel and 128/256-thread configuration on the selected GPU.
The selected variant, registers and localBytes are emitted in startup logs.
Budget, default thermal limit, telemetry protection and all fee addresses remain
unchanged. Prior explicit 0.1.0/0.1.1 selections migrate without resetting wallets.
