YSR CUDA 0.1.3 / Gozero Windows 1.0.16 — 2026-10-07

Changes:
- Per-device calibration covers 64/128/256/512 threads and 4/8/16 blocks per SM
  for both validated arithmetic paths. Median samples and a reverse-order final
  pass replace the old fastest-of-three selection. A <2% timing difference keeps
  the best old launch topology. Timing noise and driver clocks can still vary.
- Reuses native argument memory. Async counter clear, launch and blocking result
  copy replace the extra whole-context fence. Work is counted only AFTER the
  blocking result copy confirms completion. Targets upload only on change.
- Keeps the 80ms adaptive target, raises maximum range from 134217728 to
  268435456 nonces for faster GPUs. Repeated overflow ranges are not double-counted.
- Reuses the already verified CPU digest in the queue wait loop. Keeps an
  independent verification at actual submission.
- Logs distinguish expired jobs and retargeted candidates. stale = their sum;
  neither is a pool rejection. Submission exceptions and overflow retries are
  counted separately. Work preceding an idle poll is no longer discarded from
  the local rate interval.

Unchanged: SHA-256d consensus, upstream sources/provenance, fee wallets and fee
scheduler, configured temperature cutoff, performance budget and GPU identity.
No overclocking or removal of protections. UI 100% remains 90% host duty; this is
not a hard GPU utilization/power cap because previously queued GPU work can run.

Validation:
- Native GPU selftest: 17 independent hash vectors, 144 complete candidate sets
  across both variants, all thread shapes, single/multi-block tails, high nonce,
  equality and result overflow. Actual reusable batch runner is exercised.
- Additional instruction/word-comparison and paired-nonce experiments passed
  differential hashes but did not establish a stable performance advantage.
  They are retained as experiments and NOT selected by the production core.
- 120 automated application/protocol checks passed.
- Local HTTP mock integration with the app's balanced process guard accepted
  436 independently checked nonces across two job headers; zero invalid hashes.
  It exercised easy-target overflow, a same-job difficulty update, job rollover,
  stop-file exit and session close. These are simulated-pool checks, not rewards.
- Four-language UI smoke verified core installation and no automatic mining.
