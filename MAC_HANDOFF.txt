RESEARCH / SOURCES (fetched 2026-10-06)
1. Innovlab https://noid.innovlab.cc/
   Its /app.js?v=0.1.94-gb-recommended contains endpoint/protocol documentation.
   Local snapshot: .local/noid-mac-research/innovlab_js.txt (ignored by Git).
   Recommends INVminer, GB Parano1d Miner and Fl4shMiner.
   NOID endpoints: eu2.innovlab.cc, eu.innovlab.cc, hk2.innovlab.cc,
   hk.innovlab.cc, us.innovlab.cc, us2.innovlab.cc, ru.innovlab.cc,
   stratum.innovlab.cc; TLS port 19601. These are documented endpoints;
   connection and accepted-share tests have NOT been performed for Mac.
   Stratum: newline JSON; 4 MiB hard line limit; subscribe -> authorize ->
   notify -> submit. mining.pause requires immediate work cancellation until
   new notify. Complete handshake within 60 seconds; fully silent sessions may
   close after 600 seconds. Bounded reconnect/backoff required.
   Notify uses object in params[0], nonce_field_index 10, nonce_bits 64,
   256-byte pow_fields_hex, 32-byte LE targets, namespace verbatim in nonce
   high 8 bytes; submit [job_id, nonce_32hex, work_domain_id].
   Optional miner.stats reports display rate, not evidence of accepted work.

2. INVminer https://github.com/getrigeos/INVminer-Release
   Latest observed v0.1.85; binary-only per release description; no source
   offered for independent rebuild. Linux x86_64 CUDA12/13 assets; no Mac.
   NOID CPU mode --cpu-only; NOID fee 1%, QUAN fee 2% (upstream statements).

3. GB Miner https://github.com/gustlborg/gb-parano1d-miner
   Latest observed v2.17.9. Repo tree has README.md and LICENSE only.
   Proprietary, binary-only; Windows/Linux/HiveOS CUDA. No Mac asset.
   Public docs mention per-GPU-architecture kernels, tuning for hash/W,
   failover and restoring user settings. Their speed claims are not verified.
   Documents Innovlab/Suprnova Stratum and parano1d/ariabrain HTTP pools;
   the HTTP pool endpoints have not yet been verified. Do not guess them.
   Research used public README/license, not analysis of their binary.

4. Suprnova https://noid.suprnova.cc/StartMining
   Recommends Suprminer v1.9.27 and Fl4shMiner v1.5.0 (versions checked).
   Observed Windows/Linux assets, no macOS versions.
   Protocol https://noid.suprnova.cc/stratum/stratum-protocol.md
   Vectors https://noid.suprnova.cc/stratum/noid-poseidon2b-vectors.json
   EU noid.suprnova.cc; APAC stratum-apac.suprnova.cc;
   US stratum-us.suprnova.cc; EU2 stratum-eu2.suprnova.cc.
   TCP3337 / TLS3341. Same named parano1d-stratum-v1 protocol. Treat each pool's
   optional lifecycle and timeout rules separately, test both adapters.
   Do not disable certificate checks or silently assume TLS/TCP equivalence.

5. Reusable public consensus implementation
   https://github.com/proof-native/parano1d
   Apache-2.0, Copyright (C) 2026 Paranoid Zero.
   Main commit verified: d1a7e8b0816b29029e2066bf9a974253bb4a07c8
   noid_poseidon2b/src/batch_aarch64.rs is the key Apple CPU reference:
   NEON/PMULL, four interleaved independent permutations, aes target feature.
   batch.rs dispatches by noid_core::cpu::pmull_available().

   Other paths: noid_chain/src/consensus/pow.rs; noid_miner/src/pow.rs;

   No public Metal backend found in inspected tree. ARM CPU implementation
